# Day 3 – Python Data Structures (Lists, Tuples, Dictionaries and Sets)

The third day of my Industrial Training in Artificial Intelligence and Machine Learning focused on Python Data Structures. We learned how different types of data can be stored, organized, accessed, and modified using Python. These data structures are important in AI and Machine Learning because they help manage datasets, features, labels, model configurations, and other information.

We started with **Lists**, which are ordered and mutable collections. We explored different list operations such as adding, removing, updating, sorting, and accessing elements using indexing and slicing. We also practised finding pairs of numbers whose sum matches a given value and filtering unwanted data from lists.

Next, we studied **Tuples**, which are ordered but immutable collections. We understood tuple packing, unpacking, and wildcard unpacking. We also learned how tuples can be used to store fixed information, such as image dimensions and dataset details.

After that, we explored **Dictionaries**, which store data in key-value pairs. We learned how to access, update, add, and retrieve dictionary elements using methods such as `get()`, `keys()`, `values()`, and `items()`. We also understood how dictionaries can store machine learning model configurations and hyperparameters.

Finally, we studied **Sets**, which are unordered collections of unique elements. We learned how sets automatically remove duplicate values and explored operations such as union, intersection, difference, and symmetric difference. These operations are useful for identifying unique and common classes in datasets.

### Topics Learned

* Introduction to Python Data Structures
* Lists:

  * Indexing and Slicing
  * Adding and Removing Elements
  * `append()`, `extend()`, `insert()`, `remove()` and `pop()`
  * Sorting using `sort()` and `sorted()`
  * Filtering and Finding Pairs in Lists
* Tuples:

  * Ordered and Immutable Collections
  * Tuple Packing and Unpacking
  * Wildcard Unpacking
  * Converting Tuples into Lists and Vice Versa
* Dictionaries:

  * Key-Value Pairs
  * Dictionary Access and Updating
  * `get()`, `keys()`, `values()` and `items()`
  * Hashability of Dictionary Keys
* Sets:

  * Unique Elements and Duplicate Removal
  * Union, Intersection and Difference
  * Symmetric Difference
* Introduction to List Comprehensions
* Applications of Data Structures in AI/ML

### Practical Work

During the practical session, we implemented different Python programs to understand how these data structures work.

Some of the exercises included:

* Performing different operations on lists and filtering unwanted values.
* Finding pairs of numbers whose sum is equal to a given target.
* Checking password length using lists and loops.
* Unpacking tuples containing training, validation, and testing data.
* Creating dictionaries to store student details and machine learning model configurations.
* Converting text into numerical indices using a vocabulary dictionary.
* Removing duplicate elements from lists using sets.
* Finding common and unseen class labels using set operations.

We also worked on two important AI/ML-related practical problems:

1. **Confusion Matrix and Evaluation Metrics:** Used actual and predicted labels to calculate True Positives (TP), True Negatives (TN), False Positives (FP), and False Negatives (FN). We stored these values in a dictionary and calculated model accuracy.

2. **Customer Dataset Preprocessing:** Created a simple data-cleaning pipeline using lists, tuples, and sets. We removed duplicate records, filtered out invalid records containing negative salaries, counted the remaining records, and calculated the average age of customers who purchased a subscription.

### Learning Outcome

By the end of Day 3, I gained a better understanding of Python's four important data structures and their practical applications. I also learned how to organize, filter, clean, and process data using different Python operations. These concepts provided a foundation for understanding how datasets are handled during AI and Machine Learning development.
