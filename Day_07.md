# Day 7 – Introduction to Data Visualization Using Matplotlib

On Day 7 of my AI and Machine Learning training, I started learning about **Data Visualization**, which is an important part of data analysis. Data visualization helps us understand data by representing it through graphs, charts, and plots instead of looking at large amounts of numerical information.

I learned about the **Matplotlib** library in Python, which is commonly used to create different types of graphs. It helps us identify patterns, compare values, understand trends, and present information in a simple visual form.

## Topics Learned

* **Introduction to Data Visualization:** Learned how data can be represented visually using graphs and charts to make information easier to understand and analyze.

* **Introduction to Matplotlib:** Learned about Matplotlib, a Python library used to create static graphs and visualizations.

* **Line Plot:** Learned how to create line graphs to represent changes and trends in data, such as temperature changes over time.

* **Bar Chart:** Learned how to use bar charts to compare values between different categories, such as the marks obtained by students in different subjects.

* **Scatter Plot:** Learned how scatter plots represent the relationship between two numerical variables and help identify patterns in data.

* **Histogram:** Understood how histograms show the distribution and frequency of numerical values, such as the distribution of students' marks.

* **Pie Chart:** Learned how to represent data as different portions of a whole using a pie chart.

* **Graph Customization:** Practised adding titles, labels, legends, grid lines, and changing figure sizes to make graphs more meaningful and readable.

## Practical Work

* Created line plots to visualize changes in numerical values.
* Created bar charts to compare different categories.
* Used scatter plots to understand relationships between two variables.
* Created histograms to study the distribution of data.
* Created pie charts to represent percentage-based information.
* Practised customizing graphs using titles, axis labels, legends, and grid lines.
* Used sample datasets to understand how visual representations make data easier to interpret.

## Learning Outcome

By the end of Day 7, I understood the importance of data visualization in data analysis and machine learning. I learned how to use Matplotlib to create different types of graphs and represent numerical information visually.

I also understood that visualizations help us identify patterns, trends, distributions, and relationships in datasets, making it easier to understand data before applying machine learning algorithms.
