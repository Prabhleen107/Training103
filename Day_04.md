# Day 4 – Python Functions and Modular Programming

Today, I learned about **Functions and Modular Programming in Python**. Functions are an important part of programming because they allow us to divide a large program into smaller and reusable blocks of code. Instead of writing the same code repeatedly, we can define a function once and call it whenever required. This makes programs easier to understand, manage, test, and maintain.

Functions are also widely used in Artificial Intelligence and Machine Learning for performing tasks such as data preprocessing, calculating evaluation metrics, handling model configurations, and organising different steps of an ML workflow.

## Topics Learned

* **Built-in Functions:** Learned about Python's built-in functions, which are already available and can be used directly without defining them. Practised commonly used functions such as `len()`, `sum()`, `max()`, `min()`, `abs()`, `round()`, and `print()`. These functions help perform basic calculations, find dataset sizes, calculate values, and display results.

* **Custom Functions:** Learned how to create our own functions using the `def` keyword. Understood how to define a function, write statements inside it, and call it whenever needed. Also practised creating functions for different operations, such as addition, subtraction, multiplication, and generating multiplication tables.

* **Parameters and Arguments:** Understood how functions accept information through parameters and arguments. A parameter is a variable written inside the function definition, whereas an argument is the actual value passed when calling the function. This helps us create flexible functions that can work with different input values.

* **Return Statement:** Learned how to use the `return` statement to send a calculated result back from a function. Understood the difference between `print()` and `return`. Printing only displays the result, whereas returning allows us to store the result in a variable and use it in other calculations.

* **Types of Arguments:** Explored different ways of passing values to functions, including positional arguments, keyword arguments, and default arguments. Also learned about variable-length arguments using `*args` and `**kwargs`, where `*args` collects multiple positional arguments into a tuple and `**kwargs` collects multiple keyword arguments into a dictionary.

* **Variable Scope:** Learned about local and global variables and understood how the location of a variable determines where it can be accessed. Also studied the `global` keyword, which allows us to modify a global variable from inside a function.

* **Recursive Functions:** Learned about recursion, where a function calls itself to solve a problem. Understood the importance of a base case to stop recursion and a recursive case to continue the process. Practised recursion through factorial and Fibonacci sequence examples.
