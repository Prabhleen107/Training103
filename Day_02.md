# Day 2 – Python Operators, Loops and Control Flow

The second day of my Industrial Training in Artificial Intelligence and Machine Learning focused on understanding Python operators, loops, and control flow statements. We started with a quick revision of Day 1 concepts, including variables, data types, mutability, type casting, and memory references.

After the revision, we explored different types of operators in Python and learned how they are used to perform calculations, compare values, and make logical decisions. We studied arithmetic, comparison, logical, assignment, bitwise, membership, and identity operators. We also practised using these operators in different conditions and small programming problems.

Next, we learned about loops in Python, which help execute a block of code repeatedly. We covered `for` and `while` loops, along with the `range()` function. We also understood loop control statements such as `break`, `continue`, and `pass`, which help control the execution of loops. Additionally, we learned about the loop `else` clause and functions like `enumerate()` and `zip()`.

Finally, we studied control flow statements such as `if`, `elif`, and `else`. These statements help a program make decisions based on given conditions. We applied these concepts to solve different logical and practical programming problems.

### Topics Learned

* Revision of Python Variables and Data Types
* Arithmetic Operators
* Comparison and Relational Operators
* Logical Operators (`and`, `or`, `not`)
* Assignment Operators
* Bitwise Operators
* Membership Operators (`in`, `not in`)
* Identity Operators (`is`, `is not`)
* Conditional Statements (`if`, `elif`, `else`)
* Truthy and Falsy Values
* Ternary Conditional Expressions
* `for` and `while` Loops
* `range()` Function
* Loop Control Statements:

  * `break`
  * `continue`
  * `pass`
* Loop `else` Clause
* Iteration using `enumerate()` and `zip()`

### Practical Work

During the practical session, we implemented several Python programs to apply the concepts learned.

Some of the programs and exercises included:

* Checking whether a number is positive, negative, odd, or even.
* Finding the greatest among three numbers.
* Checking whether a number is prime.
* Calculating the percentage of marks obtained in different subjects.
* Generating multiplication tables using loops.
* Checking password strength based on password length.
* Using bitwise operators to check whether a number is odd or even.
* Validating password attempts using loops and `break`.

We also developed two practical mini-programs:

1. **ATM Simulator:** Created a menu-driven ATM program that allows users to check their balance, deposit money, withdraw money, and exit. We used a `while` loop and conditional statements to manage different operations while preventing withdrawals beyond the available balance.

2. **Shopping Cart Program:** Developed a simple shopping cart that allows users to add items with prices and quantities, view the total bill, and proceed with or cancel checkout. This helped us understand how loops and conditional statements work together in a practical application.
