# Day 8 – Data Visualization Using Seaborn

On Day 8 of my AI and Machine Learning training, I continued learning about **Data Visualization** and explored the Seaborn library in Python. Seaborn is built on top of Matplotlib and provides an easier way to create attractive and informative statistical graphs.

I learned how visualization can help us explore datasets, understand relationships between different features, identify patterns, and find useful information before building machine learning models.

## Topics Learned

* **Introduction to Seaborn:** Learned about Seaborn, a Python visualization library used to create statistical graphs with better styling and fewer lines of code.

* **Difference Between Matplotlib and Seaborn:** Understood that Matplotlib provides more control over individual graph elements, while Seaborn makes it easier to create attractive statistical visualizations.

* **Scatter Plot:** Learned how to visualize relationships between two numerical variables and identify patterns or clusters in the data.

* **Box Plot:** Understood how box plots display the spread of numerical data, including the median, quartiles, and possible outliers.

* **Count Plot:** Learned how to display the number of observations in different categories, which is useful for understanding categorical data.

* **Heatmap:** Learned how heatmaps represent numerical values using different colour intensities. They are especially useful for understanding correlation between features.

* **Pair Plot:** Understood how pair plots display relationships between multiple numerical features of a dataset.

* **Distribution Plot:** Learned how to visualize the distribution of numerical values and understand how data is spread.

* **Graph Customization:** Practised adding titles, labels, legends, colour palettes, and other visual elements to improve the appearance and readability of graphs.

## Practical Work

* Created different statistical visualizations using Seaborn.
* Used scatter plots to study relationships between dataset features.
* Created box plots to identify the spread of data and possible outliers.
* Used count plots to compare values in different categories.
* Created heatmaps to understand correlations between numerical features.
* Used pair plots to compare multiple features of a dataset.
* Practised visualizing sample datasets to understand their patterns and distributions.
* Combined Pandas with Seaborn to perform basic data exploration and visualization.

## Learning Outcome

By the end of Day 8, I gained a better understanding of data visualization using Seaborn. I learned how to create different statistical graphs and use them to explore datasets more effectively.

I also understood the importance of visualizing data before applying machine learning algorithms. It helps in identifying relationships between features, understanding data distribution, detecting possible outliers, and making better decisions during data preprocessing and analysis.
